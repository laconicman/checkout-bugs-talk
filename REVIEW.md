# Review Guidelines

Companion examples for a conference talk. Tests under `src/test/` assert the surprising
behaviour as well as the countermeasure, so a passing run includes reproduced bugs.

## Critical Areas

- Every loop over `PRAGMA foreign_key_check` in `src/main/kotlin/dev/checkout/talk/OrphanCleaner.kt` must terminate for every input; flag a pass that can report rows without deleting any of them.
- A PR that adds or removes `@Test` functions under `src/test/` must update the test and class counts in the "The suite contains" sentence of `README.md`; flag a mismatch.
- A test under `src/test/kotlin/dev/checkout/talk/` that claims a fix needs a test in the suite that shows the unfixed behaviour; flag a fix whose "before" case exists nowhere.
- KDoc in `src/main/kotlin/dev/checkout/talk/` that states what Room or SQLite does must be demonstrated by a test in the repository; flag a behavioural claim that no test pins.

## Conventions

- A coroutine test in `src/test/` that proves a hang must bound the wait with `withTimeoutOrNull`; flag an unbounded `join()` or `await()` on a path that is expected to block.
- Dependencies in `build.gradle.kts` use one exact version each; flag version ranges and `+`.

## Anti-patterns to Flag

- Assertions in `src/test/` that pin a wrong-looking result (orphaned rows, `assertNull` on a transaction) are the reproduced bug; flag a change that "corrects" one, never the assertion.
- Extracting the private helpers `asMigration`, `countOf` or `foreignKeysFlag` out of a file in `src/test/`; each test file reads alone next to its slide, so the duplication stays.

## Ignore

- `gradlew`, `gradlew.bat` and `gradle/wrapper/` are generated by Gradle and do not need review.
- `execSQL("PRAGMA foreign_keys = OFF")` inside `asMigration` helpers in `src/test/` models the state Room runs migrations in; do not ask for it to be restored.
- SQL assembled by string interpolation in `src/test/` and `src/main/kotlin/dev/checkout/talk/` uses names read from SQLite or literals from the test; do not report it as injection.
- Slide numbers and talk wording in KDoc under `src/` belong to the talk; do not suggest rewording them.
